# ارائه تعاملی پایان‌نامه

بررسی مبانی ارزشی و تصمیم‌گیری به فرزندآوری — علی سلطانی میرزائی

## اجرای محلی

هر سرور استاتیک کافی است:

```bash
npx serve .
```

یا با پایتون:

```bash
python3 -m http.server 4173
```

سپس `http://localhost:4173` را باز کنید.

## استقرار در Vercel

1. این پوشه را به یک مخزن گیت بفرستید.
2. در Vercel پروژهٔ جدید بسازید و Root Directory را همین پوشه بگذارید.
3. Framework Preset را روی Other بگذارید. Build لازم نیست.

یا:

```bash
npx vercel
```
